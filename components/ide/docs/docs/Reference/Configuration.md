# Configuration

Edit `config.php` to customize the app.

| Option | Description |
|---|---|
| `site_title` | Main title in the header |
| `site_subtitle` | Short subtitle below the title |
| `docs_dir` | Folder containing Markdown documents |
| `default_page` | Page opened by default |
| `max_search_results` | Maximum search results shown |

## Default page format

Use the page path without `.md`:

```php
'default_page' => 'Getting-Started/Welcome'
```
